# MES Companion v0.6.0-test

Waveshare ESP32-S3-Touch-LCD-4.3C-BOX-CN 的 MES 日内交易辅助屏幕。

当前版本是基于 `v0.5.0` 的预发布测试版，重点改善下单后的记录流程、持仓时间提醒和联网校时确认。正式交易规则、交易日历与防止过度交易的限制保持不变。

## 版本信息

- 版本：`v0.6.0-test`（Pre-release）
- 日期：2026-10-14
- ESP32 Arduino Core：3.3.12
- LVGL：8.4.0
- 默认声音：关闭

## 本版变化

- 点击 `LONG` 或 `SHORT` 后立即记录方向，并自动返回首页
- 首页左下角显示当前方向及持仓计时，例如 `LONG 03:25`
- 持仓达到30分钟后按钮变为黄色，仅作温和视觉提醒
- 不增加声音、闪烁、弹窗或额外确认步骤
- 修复长按 `TIME CHECK | HOLD 5S TO SYNC` 时可能写入旧网络时间快照的问题
- 仍保留网络时间与 RTC 相差超过10分钟时的人工长按确认保护
- 延续显示稳定性参数：14 MHz 像素时钟、1秒界面刷新、双帧缓冲及关闭 Wi-Fi 省电

## 为什么是测试版

快速记录与30分钟提醒已经在模拟交易时段验证；本次校时修复也已成功编译并刷写。由于仍需观察多次冷启动、单独 Wi-Fi 供电和真实交易日运行，所以暂不替代正式版 `v0.5.0`。

## 恢复与安装

最简单的恢复方式是刷写 Release 中的合并固件：

```powershell
esptool --chip esp32s3 --port COM4 --baud 921600 write-flash 0x0 firmware/mes_companion.ino.merged.bin
```

将 `COM4` 替换为设备实际端口。详见 [FLASHING.md](FLASHING.md)。

## 隐藏测试命令

```text
TEST,NY,2026,11,26,12,59,50
TEST,OFF
```

测试模式仅用于开发验证，启用时屏幕底部显示 `TEST MODE`。必须使用 `TEST,OFF` 或重启退出。

## 注意

CME 官方可能临近节假日调整交易时间。年度交易日历是独立模块，后续可以只更新数据表。

12月计划中的新交易时段结构不包含在本测试版中。
