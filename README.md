# MES Companion v0.5.0

Waveshare ESP32-S3-Touch-LCD-4.3C-BOX-CN 的交易日历与可靠性正式版本。

## 版本信息

- 版本：`v0.5.0`
- 日期：2026-10-10
- ESP32 Arduino Core：3.3.12
- LVGL：8.4.0
- 默认声音：关闭

## 本版新增

- 独立的 CME MES 年度交易日历模块
- 2026 主要休市日与缩短交易日识别
- 休市日禁止开新交易
- 缩短交易日显示 `HOLIDAY HOURS`，13:00 ET 锁定
- RTC 日期落后时以固件编译日期进行安全恢复
- NTP 与 RTC 相差超过10分钟时显示 `TIME CHECK`
- 长按5秒确认异常网络校时
- 长按网络状态5秒重新进入手机配网，并显示按住进度
- 首页突出显示 13:00、14:00、-2R、5笔及假日锁定原因
- 交易页区分 `DAILY STOP`、`TRADE LIMIT` 和 `SESSION LOCKED`
- 只有普通交易日14:00锁定允许长按解锁一笔
- 隐藏串口时间模拟功能，不修改 RTC，不覆盖真实交易记录

## 隐藏测试命令

```text
TEST,NY,2026,11,26,12,59,50
TEST,OFF
```

测试模式仅用于开发验证，启用时屏幕底部显示 `TEST MODE`。必须使用 `TEST,OFF` 或重启退出。

## 注意

CME 官方说明具体节假日交易时间可能临近日期调整。日历被隔离为独立模块，后续可只更新年度数据表。

12月计划中的新交易时段结构不包含在本版中。

## Web 副屏

`docs/` 包含手机优先的 MES Companion Web 版本，可直接部署到 GitHub Pages。

- 交易时段与 K 线倒计时
- 极简全屏副屏
- 本地交易日志与纪律锁定
- 离线 PWA
- JSON 数据导入与导出

网页只提供提醒和手动记录，不连接交易账户、不发送订单，也不提供交易信号。交易数据仅保存在浏览器本地。
